# Installing the new ONENESS GLOBE theme from an Android phone

## Easiest way (recommended): the small "lite" theme + 6 PDFs

Use this if you saw **"Incompatible Archive"**. The lite theme file is small (about 2 MB). The six brochure PDFs are uploaded separately.

**Part A — install the theme**
1. Download `oneness-globe-theme-v2.0.1-lite.zip` (about 1.9 MB).
2. In WordPress: **Appearance → Themes → Add New Theme → Upload Theme**.
3. Tap **Choose File**, pick the lite ZIP from **Downloads**, tap **Install Now**.
4. If asked, tap **Replace current with uploaded**.

**Part B — upload the six PDFs (keep their names)**
1. Download the six PDF files: `one-immune-literature.pdf`, `grow-pro-literature.pdf`, `essenguard-plus-literature.pdf`, `livren-g-literature.pdf`, `optiacid-literature.pdf`, `mycoclean-plus-literature.pdf`.
2. In WordPress: **Media → Add New Media File**.
3. Tap **Select Files** and choose the six PDFs (one at a time is fine).
4. Do not rename them. The product pages find them by name automatically.

Until a PDF is uploaded, that product page simply hides its "Download PDF" button. Everything else on the page works.

## Other way: the full theme (about 7.5 MB, PDFs included)

Use this only when you are ready. Installing does **not** publish anything until you activate the theme. Keep a backup first.

## Before you start
1. Copy the file `oneness-globe-wordpress-theme-v2.0.1.zip` to your phone (Downloads folder).
2. Open the **Chrome** app and sign in to your WordPress admin page: `https://onenessglobe.com/wp-admin`
3. Tap the **⋮** menu (top right) and choose **Desktop site** so the menus match the steps below. Turn it off afterwards if you prefer.

## Step 1 — Back up the current site
1. In WordPress, go to **Tools → Export** (or use the backup feature in Namecheap EasyWP's control panel).
2. Tap **Export All**, then **Download Export File**.

## Step 2 — Upload the new theme
1. Go to **Appearance → Themes**.
2. Tap **Add New Theme** at the top, then **Upload Theme**.
3. Tap **Choose File**, select `oneness-globe-wordpress-theme-v2.0.1.zip` from Downloads, and tap **Install Now**.
4. If WordPress says the theme already exists, tap **Replace current with uploaded**. This keeps your site address and content.

## Step 3 — Check before going live
1. Do **not** tap "Activate" yet if you have a staging copy. Check on the staging copy first.
2. Visit these addresses in Chrome (replace the domain if you test on staging):
   - `https://onenessglobe.com/products/one-immune/`
   - `https://onenessglobe.com/products/grow-pro/`
   - `https://onenessglobe.com/products/essenguard-plus/`
   - `https://onenessglobe.com/products/livren-g/`
   - `https://onenessglobe.com/products/optiacid/`
   - `https://onenessglobe.com/products/mycoclean-plus/`
3. Tap a **Order on WhatsApp** button: it should open WhatsApp with the product name and "1 single pack".

## Step 4 — Activate
1. Go to **Appearance → Themes**.
2. Under **Oneness Globe Premium Catalog**, tap **Activate**.
3. If a product page shows "Page not found", go to **Settings → Permalinks** and tap **Save Changes** once. Do not change any setting on that page.

## Step 5 — Set the WhatsApp number (only if it is not already +8801339562576)
1. Go to **Appearance → Customize → ONENESS GLOBE WhatsApp Orders**.
2. Enter `8801339562576` (digits only, with country code).
3. Tap **Publish** at the top.

## If something goes wrong
- **Go back to the old theme:** Appearance → Themes → hover over the old theme (oneness-globe v1.8, if you kept it) → Activate. If you did not keep it, restore the backup from Step 1 using your Namecheap EasyWP control panel.
- **Do not** delete any products or pages. Ask for help if a message mentions "fatal error".

Tip: take a screenshot of each step if you need help from the developer.
