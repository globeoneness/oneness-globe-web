INSTALLATION
1. WordPress admin > Appearance > Themes > Add New Theme > Upload Theme.
2. Choose oneness-globe-wordpress-theme-v2.0.0.zip and tap Install Now.
3. Tap "Replace current with uploaded" if WordPress asks.
4. Tap Activate. Then open https://onenessglobe.com/products/one-immune/ to check.

EDITING CONTENT (safe method)
- Product details live in inc/product-data.php. Change a value only between the quote
  marks. Keep the commas and brackets exactly as they are. Make a backup first.
- Prices: change the 'mrp' value for a product in inc/product-data.php and keep the
  same format (e.g. 680). Prices shown on the home page come from the same place.
- WhatsApp number: WordPress admin > Appearance > Customize > ONENESS GLOBE WhatsApp
  Orders (digits only, with country code).
- Replace a product photo: upload a replacement image with the same file name to
  assets/products/ (for example one-immune.webp).
- Brochure artwork: assets/literature/ (display only). Original PDFs: assets/pdf/.
  Do not edit the PDFs; they are the approved originals.

IMPORTANT
- Items the artwork leaves unclear are listed for the company to confirm. Administrators
  see these notes at the top of each product page when logged in (not visible to visitors).
- Technical values are shown exactly as printed on the original literature.
- Keep WordPress, PHP and plugins up to date. Keep backups before any theme update.
- Certifications (GMP, ISO 9001) and registrations are shown only as printed on the
  pack artwork; this theme does not add any certification or claim.
